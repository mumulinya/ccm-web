# 工作台与菜单管理完整链路

## 工作台读取

```text
任务/项目/群聊/定时任务真实状态
→ 服务端只读聚合
→ V3首屏快照与checksum
→ 浏览器按用户缓存最近有效快照
→ Runtime Event通知变化
→ 取消旧请求并加载最新generation
→ 按区域游标加载更多
```

页面断线时继续显示最近成功数据并标记陈旧；恢复后重新读取服务端，不根据本地按钮状态猜测任务或项目状态。

## 从工作台发起需求

用户输入业务描述并只选择目标群聊或项目，也可以附加文档和图片。工作台不再选择具体会话；服务端按`workbench`来源绑定解析目标自动化会话，没有绑定时自动创建。预览继续进入统一需求摄取链，完整来源覆盖和模型计划通过后才允许确认。确认后进入原任务队列、开发、TestAgent或主 Agent自验、最终验收和任务回放，不创建工作台专属任务。

## 任务处理

1. 服务端返回用户可理解的目标、当前步骤、等待原因、下一步和允许动作。
2. 浏览器提交任务 ID、当前 revision、动作、用户补充和唯一 `client_message_id`。
3. 服务端重新读取任务并验证 RBAC、revision、阻塞类型和动作矩阵。
4. 动作通过后按原队列、确认、权限或重试链执行，并生成 `WorkbenchTaskActionReceiptV1`。
5. 并发状态变化导致 `state_drift` 时拒绝旧操作，页面刷新后由用户按最新状态继续。

终态任务不能恢复为 pending。暂停、失败、待补充、待确认和权限等待各自进入对应业务链。

## 项目操作

项目卡同时展示两个互不混淆的状态：

- Agent 协作通道：连接或断开。
- 源码运行配置：选择精确配置后启动、暂停、重新运行或构建。

Viewer 只能查看；Operator 和 Admin 可以执行项目运行。断开 Agent 时停止当前项目的源码和构建进程，但不触碰兄弟项目。

## 菜单同步

```text
Admin工作区默认
→ 当前用户个人ID级覆盖
→ RBAC禁用/可见性投影
→ 桌面侧栏、标签栏与移动导航
→ revision CAS保存
→ BroadcastChannel与Runtime Event同步
```

普通用户只能修改个人布局和个人链接。Admin 可以编辑工作区默认。工作区新增菜单会进入用户导航；已有个人顺序、分组和固定偏好继续保留。配置冲突不会静默覆盖，必须重新加载或重新应用变更。

## 安全与失败处理

- 菜单配置不能扩大服务端权限。
- 自定义链接仅允许无凭据的 HTTP/HTTPS URL。
- 图标不能包含 HTML、脚本、SVG 源码或外部 URL。
- 工作台快照不包含源码路径、PID 文件或 Provider 协议。
- GET 请求不执行归档、PID 清理或任务状态写入。
- 所有 Provider 调用为零；工作台与菜单状态完全来自结构化系统事实。
