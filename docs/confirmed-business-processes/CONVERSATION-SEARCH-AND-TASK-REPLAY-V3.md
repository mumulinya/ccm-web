# 会话搜索与任务回放完整流程（任务回放 V5）

## 会话搜索

```text
全局/群聊/项目/音乐会话写入
→ 标记索引需要更新
→ 后台Worker读取精确授权来源
→ 构建不可变搜索generation
→ 校验来源checksum并原子启用
→ 用户筛选、分页和搜索
→ 读取命中消息前后窗口
→ 跳转精确会话与消息
```

首次没有可用索引时页面显示正在构建；重建期间使用last-good结果并明确陈旧状态。搜索不会触发模型调用，也不会改变原会话。收藏只保存用户、消息行身份和来源checksum。

## 任务回放

```text
任务创建与执行
→ 各领域写入结构化事件和canonical证据
→ 回放读取任务族与关联来源
→ 生成来源manifest和事件快照
→ 生成用户可读结论、记录完整度、因果链、验收矩阵与尝试对比
→ 页面先展示结果、当前阶段、下一步和待处理事项
→ 事件按游标分页读取
→ 实时阶段只增量刷新事件
→ 终态停止轮询并保留完整历史
```

用户默认看到目标、当前阶段、下一步、完成内容、验证、文件与风险。回放按“需求、计划、实现、验证、返工、交付”六章组织完整任务链；每章可展开查看相关轮次、问题和时间线定位。任务列表直接显示当前阶段和待处理数量。

验收矩阵逐项展示验收标准、结果、验证者、Evidence引用及新鲜度。缺少结构化覆盖时显示“未运行/未记录”，代码或证据变化后显示“已陈旧”，绝不从自由文本猜测通过。历史失败只有存在结构化解决记录、后续复验通过或最终Terminal Gate通过时才显示为已解决或已被最终结果取代。

完整时间线是第二层详情：运行中默认展开并实时更新，终态默认折叠；支持阶段、状态、参与者、子任务、问题和全文摘要筛选。Provider、session、generation、MCP、Skill、checksum和机器轨迹位于独立“技术详情与记录保留”，不会混进用户结论。计划、执行、TestAgent验收、返工与最终交付使用同一任务身份，重复来源事件会合并但原始事实不删除。

任务执行记录与任务回放职责不同：执行记录服务当前消息的实时过程；任务回放服务整个根任务及全部子任务的事后理解、验收审计、返工追踪和最终交付。两者复用同一任务与Evidence事实源，不建立第二套状态机。

执行事件通过 `ccm-task-event-link-v1` 绑定任务、作用域、精确会话、消息锚点、generation、attempt及可用的计划步骤、工作项、批次和Evidence。执行记录可进入对应回放事件；回放可返回原消息并展开对应执行行。缺少历史锚点时只打开任务回放，不猜测其他会话。

回放V5按“结果与下一步、记录完整度、因果链、验收标准、尝试对比、需求与交付、计划与分工、中断恢复、完整时间线”展示。完整度只使用 `complete / mostly_complete / partial / legacy` 四级语义，并列出第三方Agent未主动汇报、历史任务缺少结构化验收等真实缺口，不计算伪精确百分比。因果链只使用显式计划步骤、工作项、工具批次、依赖、文件、验证和验收引用；旧记录采用保守关联。

同一WorkItem的失败、返工和最终accepted attempt并排保留；被替代尝试不能进入最终文件卡。跨项目依赖明确记录等待、隔离执行、群聊主Agent验收、合并和唤醒。第三方Agent没有主动业务进度时显示“当前仅有系统观察记录”，不把记录缺口解释为没有执行。

普通`use`用户只获得业务投影和可打印用户报告；资源`manage`用户及管理员才可读取排障事件与安全审计JSON。新鲜度接口只返回仓库、文件和Evidence的当前、漂移、删除、权限撤销状态。所有导出均不含源码正文、Prompt、密钥、原始stdout、隐藏思维或第三方原生会话ID，并使用`private, no-store`。

完整时间线超过300行时使用测量虚拟化并继续游标分页；执行记录的长行使用浏览器内容可见性隔离，避免折叠详情和实时追加导致整页重排。筛选、焦点事件、展开状态、消息滚动和草稿按会话或任务隔离恢复。

## 失败与恢复

- 搜索构建失败：保留last-good索引；首次无索引时返回`index_building`，不伪装成零结果。
- 消息窗口失效：返回`message_anchor_stale`并要求刷新结果。
- 回放来源变化：生成新checksum与manifest，旧事件快照不在切换前删除。
- 回放证据暂不可读：保留摘要与事件，页面明确显示证据读取失败。
- 证据与当前RepoState不一致：验收项标记为陈旧，不能作为当前强证据。
- 历史任务缺少结构化验收覆盖：保留历史终态，但验收矩阵明确显示未记录，不补造通过证据。
- `failed | blocked | cancelled | completed`释放实时轮询；历史自由文本不能改变终态。

## 上线门禁

- 四类会话与飞书来源均可检索且严格隔离。
- 长消息末尾内容可命中，不存在12K字符裁剪。
- 收藏不落浏览器公共正文存储。
- 任务事件可分页，实时刷新不重复传输大型证据。
- 阻塞任务终止轮询，未知历史状态不猜测。
- Provider调用为0。
- 执行记录与任务回放双向精确定位，旧generation和旧attempt不能覆盖accepted attempt。
- 用户报告可通过专用打印投影保存PDF；审计JSON必须通过资源管理权限门禁。
