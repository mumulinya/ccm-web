# 会话搜索与任务回放完整流程

## 会话搜索

```text
全局/群聊/项目/音乐会话写入
→ 标记索引需要更新
→ 后台Worker读取精确授权来源
→ 构建不可变搜索generation
→ 校验来源checksum并原子启用
→ 用户筛选、分页和搜索
→ 读取命中消息前后窗口
→ 跳转精确会话与消息
```

首次没有可用索引时页面显示正在构建；重建期间使用last-good结果并明确陈旧状态。搜索不会触发模型调用，也不会改变原会话。收藏只保存用户、消息行身份和来源checksum。

## 任务回放

```text
任务创建与执行
→ 各领域写入结构化事件和canonical证据
→ 回放读取任务族与关联来源
→ 生成来源manifest和事件快照
→ 页面先展示目标、状态、计划和证据目录
→ 事件按游标分页读取
→ 实时阶段只增量刷新事件
→ 终态停止轮询并保留完整历史
```

用户默认看到目标、当前阶段、下一步、完成内容、验证、文件与风险。Provider、session、generation、MCP、Skill、checksum和技术轨迹位于二次展开的排障信息。计划、执行、TestAgent验收、返工与最终交付使用同一任务身份，重复来源事件会合并但原始事实不删除。

## 失败与恢复

- 搜索构建失败：保留last-good索引；首次无索引时返回`index_building`，不伪装成零结果。
- 消息窗口失效：返回`message_anchor_stale`并要求刷新结果。
- 回放来源变化：生成新checksum与manifest，旧事件快照不在切换前删除。
- 回放证据暂不可读：保留摘要与事件，页面明确显示证据读取失败。
- `failed | blocked | cancelled | completed`释放实时轮询；历史自由文本不能改变终态。

## 上线门禁

- 四类会话与飞书来源均可检索且严格隔离。
- 长消息末尾内容可命中，不存在12K字符裁剪。
- 收藏不落浏览器公共正文存储。
- 任务事件可分页，实时刷新不重复传输大型证据。
- 阻塞任务终止轮询，未知历史状态不猜测。
- Provider调用为0。
