# 项目管理工作区布局升级

## 目标

项目管理页面采用稳定的办公工作区结构，降低顶部操作竞争，明确区分 Agent 连接、源码运行、会话管理和项目对话。

## 页面结构

```text
项目上下文栏
  当前项目 / 协作状态 / 项目主 Agent / 项目操作

源码运行栏
  运行配置 / 进程状态 / 启停重启 / 构建 / 日志

主工作区
  左：精确项目会话列表
  右：当前会话消息、搜索、权限、上下文和输入框
```

Agent 连接与源码运行继续保持不同业务语义。顶部只保留当前操作需要的信息，不再同时展示冗长项目统计。

## 交互

- 左右区域等高，页面本身不跟随会话列表滚动。
- 会话列表和消息区域分别独立滚动。
- 无会话时，右侧只展示一个明确的“新建会话”主操作。
- 项目高级操作收纳到统一菜单，连接 Agent 与新建项目保持可直接访问。
- 运行栏在桌面端单行排列，在移动端拆为配置、状态和横向操作组。
- 移动端会话列表继续使用抽屉，不挤压对话宽度。

## 视觉约束

- 使用当前主题的 surface、border、control 和 accent Token。
- 不使用额外装饰卡片、渐变背景或大面积营销式标题。
- 图标按钮保留 tooltip，文本命令只用于连接、构建和创建等明确动作。
- 稳定高度和网格列防止状态、PID、按钮或项目名称改变页面尺寸。

## 验证

- 前端 production build 通过。
- 项目管理渲染回归覆盖桌面、移动端、空会话、运行配置、项目登录配置和会话抽屉。
- 所有场景无页面横向溢出、控制台错误或重复空状态。
- 测试不调用付费 Provider。
