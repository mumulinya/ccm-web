# 设置中心全宽布局

日期：2026-07-23

## 问题

设置中心的标题区域和主体布局都使用 `width:min(1120px,100%)`。宽屏环境下，左侧设置导航与右侧表单只占页面左半部分，右侧留下大面积没有参与布局的空间。

## 当前行为

- 设置页标题和主体布局宽度统一为当前页面可用宽度的 `100%`。
- 左侧设置导航保持 `220px`，保证栏目名称和说明稳定可读。
- 右侧设置面板使用 `minmax(0,1fr)` 占用全部剩余宽度。
- 导航与表单之间的间距使用 `clamp(24px,2vw,36px)`，在普通桌面和宽屏上都保持合理比例。
- 通知、统一模型、开发 Agent、外观、安全和系统面板共享同一宽度契约。
- `820px` 以下继续切换为顶部横向设置导航和单列表单。

## 修改范围

- `frontend/src/components/settings/settings.css`
- `scripts/settings-render-regression.mjs`

设置数据、登录、凭据保存、Agent 检测和飞书配置业务没有改变。

## 验证

- frontend production build 通过。
- `1680px` 浏览器中页面可用宽度、标题宽度和主体布局宽度均为 `1374px`。
- 标题、主体和右侧表单边缘误差不超过 `1px`。
- 通知、模型、系统三个桌面分区以及 `390px` 移动端均无横向溢出。
- 技术详情默认折叠，移动端设置导航保持在视口范围内。
- 测试使用 mock API，付费 Provider 调用为 `0`。

视觉证据位于 `scratch/settings-render-regression/`，该目录为本地测试产物，不进入 Git。
