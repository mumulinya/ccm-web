# 全页面主题背景一致性

## 目标

CCM 的页面、面板、输入控件、下拉选项、弹窗和状态区域统一消费当前主题变量。用户切换系统默认、深邃极客、赛博之霓、深海探索或极地流光后，不再出现与当前配色无关的固定白底。

## 统一主题契约

共享表面变量：

- `--bg-primary`：页面背景。
- `--surface`：主要内容表面。
- `--surface-raised`：弹窗、悬浮菜单和抬升控件。
- `--surface-translucent`：需要透明度的抽屉和遮罩上层。
- `--surface-subtle`：次级卡片与列表行。
- `--control-bg`：输入框、下拉框和文本域。
- `--overlay-scrim`：模态遮罩。
- `--info-soft`、`--success-soft`、`--warning-soft`、`--danger-soft`：状态语义背景。

非默认主题从自己的 `--surface`、`--bg-primary` 和强调色派生这些变量，不继承另一套深色主题的固定色相。

## 页面覆盖

本次扫描并收口：

- 群聊、项目、全局 Agent 共用的消息输入、附件、模板、消息导航和上下文占用弹层。
- 记忆中心、工作台、设置、工具配置和项目工具弹窗。
- 任务卡、主 Agent 决策、权限审批、任务回放和 Agent 代码变更抽屉。
- 知识库列表与检索、代码 Diff/提交面板和终端提示。
- 宠物列表、资源卡、皮肤卡与创建弹窗。

保留固定白底的范围只有：独立登录页的显式浅色皮肤、二维码识别画布和开关滑块圆点。它们不是应用页面表面，固定白色用于识别或对比。

## 原生控件

`select`、`option` 和 `optgroup` 显式继承 `color-scheme`，并使用 `--control-bg` 与 `--text-primary`。浏览器自动填充、禁用态和 placeholder 同样使用主题变量。截图中群聊下拉菜单的系统白底问题由此修复。

## 移动端

旧主题的超大渐变伪元素会把移动文档宽度撑到视口之外，现已移除。关闭状态的群聊操作弹层不再参与布局；协作状态弹层在移动端改为右对齐并限制到视口宽度。

## 防回归

- `node scripts/theme-background-contract-selftest.mjs`
  - 扫描全部 Vue/CSS 页面，拒绝未经批准的固定白色表面。
  - 检查主题变量、原生下拉规则、预设派生色和关键页面契约。
- `node scripts/theme-background-render-regression.mjs`
  - 在真实 Chromium 中验证深海主题的群聊、记忆中心、设置页和移动端。
  - 核对实际计算颜色、下拉选项前景/背景和横向溢出。
  - 证据输出到 `scratch/theme-background-render-regression/`。

主题静态回归已加入 `frontend` 测试域和日常 `quick` 套件。测试不调用付费 Provider。
