# Agent 性能范围与执行记录分页

## 页面行为

- 性能监控支持今天、近 7/14/30/90 天和全部历史。
- 时间范围同时影响指标卡、趋势、状态分桶和执行记录，不再只修改图表。
- 执行记录不再固定截取 30 条，改为服务端分页。
- 可筛选全部、成功、失败和取消，筛选按钮展示当前时间范围内的真实数量。
- 每页支持 10、20、50 条，并提供首页、上一页、下一页和末页。
- 切换群聊、全局范围、时间或状态后自动回到第一页。

## 数据边界

`GET /api/metrics/events` 接收 `scope_type`、`scope_id`、`days`、`status`、`page` 和 `page_size`。过滤与分页在服务端完成，群聊和全局数据保持严格隔离。

性能事件保留上限由 1200 条提升为 10000 条。“全部历史”表示当前权威性能存储中保留的全部记录；此前已经因旧上限清理的数据无法反向恢复。

## 验证

`scripts/agent-metrics-pagination-selftest.mjs` 使用本地构造数据验证分页、状态筛选、作用域隔离和页面控件，不调用模型或外部服务。
