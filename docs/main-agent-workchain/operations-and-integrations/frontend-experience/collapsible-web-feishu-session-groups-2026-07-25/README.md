# Web 与飞书会话折叠分组

## 行为

全局助手和项目管理页面继续按来源严格区分 Web 会话与飞书会话，但侧栏不再默认铺开全部历史记录：

- 初次打开时只显示“网页会话”和“飞书会话”两行分组标题及数量。
- 点击某个分组标题只展开该分组，再次点击收起。
- 两个分组互不影响，可以同时展开、同时收起或只展开一个。
- 箭头方向和 `aria-expanded` 同步反映真实状态，键盘用户可以直接操作标题按钮。
- 全局助手和项目管理分别保存展开状态，不互相覆盖。

## 数据边界

本次只调整展示状态，不改变会话数据：

- Web/飞书来源判定、当前会话、消息正文和压缩边界保持不变。
- 飞书绑定标志、目标名称、创建、删除、重命名和绑定操作保持原入口。
- 折叠状态只保存在浏览器 `localStorage`，不会写入服务端会话或记忆。
- 折叠不会停止消息加载、SSE 更新或飞书投递。
