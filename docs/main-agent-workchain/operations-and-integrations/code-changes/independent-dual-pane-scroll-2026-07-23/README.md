# 代码协作等高双面板独立滚动

日期：2026-07-23

## 目标

代码协作页的变更目录和 Diff 查看器是两个职责不同的工作区域。桌面端不再让左侧目录滚轮推动整个页面，也不再让用户在向下浏览 Diff 后丢失文件选择位置。

## 当前布局

- 顶部项目、Git 同步、变更摘要和任务来源区域保持在代码工作区上方。
- 剩余可用高度全部交给双栏工作区，不再使用固定 `900px` 长页面。
- 左侧文件面板与右侧 Diff 面板顶边和底边对齐，拥有相同高度、独立边框、背景和阴影。
- 左侧搜索、分组、状态筛选和“选择当前文件”保持固定，只有文件树滚动。
- 右侧文件名、Diff 搜索和查看操作保持固定，只有 Diff 内容滚动。
- 两侧都使用 `overscroll-behavior: contain`，滚动到边界时不会继续推动代码协作外层页面。
- 长代码行继续在右侧面板内部横向滚动，不扩大页面宽度。

移动端使用上下两个等高面板。代码协作工作台本身允许纵向切换到下方 Diff，但文件树和 Diff 内容仍分别拥有独立滚动区域。

## 修改范围

- `App.vue`：代码协作标签页恢复为固定、不可滚动的内容容器。
- `CodeChanges.vue`：剩余高度使用 `340px + 自适应` 网格，并为移动端提供上下等高布局。
- `CodeChangeFileList.vue`：文件树成为左侧唯一纵向滚动容器。
- `CodeDiffViewer.vue`：Diff 成为右侧唯一纵向和横向滚动容器。
- `code-changes-render-regression.mjs`：使用 39 个文件和长 Diff 验证真实滚动隔离。

Git 状态读取、目录分组、暂存、回滚、提交、推送和权限门禁没有改变。

## 验证

- 静态代码协作能力回归：`24` 个检查通过。
- Playwright 代码协作回归：`6` 项通过。
- 浏览器验证左右面板高度误差不超过 `1px`。
- 浏览器先滚动文件树，确认 Diff 和外层页面位置不变；再滚动 Diff，确认文件树和外层页面位置不变。
- 桌面与 `390px` 移动端均无页面横向溢出。
- frontend production build 通过。
- 测试只使用 mock Git/API 数据，未连接用户仓库，付费 Provider 调用为 `0`。

视觉证据位于 `scratch/code-changes-render-regression/`，该目录为本地测试产物，不进入 Git。
