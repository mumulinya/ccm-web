# 可调节项目运行控制台

项目运行日志采用 IDEA 风格底部工具窗口：

- 拖动控制台顶部水平分隔条可上下调整日志区域高度。
- 向上拖显示更多日志，向下拖为会话区域留出更多空间。
- 高度受当前工作区和移动端视口约束，不允许遮住整个页面或缩小到不可操作。
- 调整结果保存在浏览器，下次打开项目运行日志继续使用。
- 双击分隔条恢复默认高度。
- 分隔条聚焦后可使用上下方向键调整，`Shift` 配合方向键进行大步调整，`Home`/`End` 切换最小/最大高度。
- xterm 的 `ResizeObserver` 会跟随高度变化重新计算行列数。

验证脚本：`scripts/project-run-console-resize-selftest.mjs`。
