# 在线文档公开链接统一读取

## 已确认业务目标

CCM 将在线文档视为与本地附件同级的权威需求资料。用户可以在全局助手、群聊、项目会话、任务派发、定时任务、自动开发入口和知识库中粘贴腾讯文档或其他 HTTP/HTTPS 文档链接。

所有入口共用 `source-ingestion`，不再由页面或 Agent 各自抓取正文。

## 统一流程

```text
用户粘贴链接
→ 前端识别为在线文档引用
→ 后端验证协议、域名与公网地址
→ 按 12 MB 上限读取
→ 解析 HTML、文本、JSON、XML 或 PDF
→ 保存来源、状态、解析器和摘要
→ 将可读正文注入精确会话或任务
→ Agent 按来源正文理解、规划、执行和验收
```

当链接不可读时，来源记录保留，但正文不会进入模型上下文：

```text
需要登录或无权限 → needs_authorization
不支持的格式     → unsupported
网络或解析失败   → failed
```

Agent 会收到明确的“未读取正文”约束，不得根据链接名称猜测内容。

## 入口覆盖

| 入口 | 支持本地附件 | 支持在线文档 | 资料进入位置 |
| --- | --- | --- | --- |
| 全局助手 Web / 飞书 | 是 | 是 | 当前全局会话和本轮主 Agent 上下文 |
| 群聊 Web | 是 | 是 | 当前精确群聊会话和主 Agent 上下文 |
| 项目 Web / 飞书 | 是 | 是 | 当前精确项目会话和项目主 Agent 上下文 |
| 自动开发 / 需求池 | 是 | 是 | 需求集合、拆解计划和任务来源 |
| 任务派发 | 是 | 是 | 任务附件、执行上下文和验收上下文 |
| 定时任务 | 是 | 是 | 定时任务附件与每次执行上下文 |
| 知识库 | 是 | 是 | 指定全局、群聊、项目或 Agent 知识范围 |

任务派发和定时任务即使没有本地文件，只要描述中包含在线文档链接，也会创建正式资料记录。编辑任务时按来源 ID 去重，不会重复注入。

## 腾讯文档公开分享

- 用户在腾讯文档中将权限设为“获得链接的人可查看”。
- 用户把完整的 `https://docs.qq.com/...` 地址直接发送给 Agent，无需进入设置中心。
- CCM 只使用普通公开 HTTP 请求读取正文，不发送 Cookie、Authorization、OAuth Token 或开放平台凭据。
- 登录页、申请权限页、访问密码、动态页面或导出受限页面均视为不可读，状态记录为 `needs_authorization` 或 `failed`。
- 不可读正文不会进入模型上下文，Agent 只能提示用户调整分享权限或改为上传 PDF、DOCX 等附件。
- 已移除设置中心的腾讯文档配置页、开放平台应用、OAuth 回调、中转服务和兼容凭据接口。

## 网络与内容边界

- 只允许 HTTP/HTTPS。
- DNS 解析到本机、局域网、链路本地或保留地址时拒绝读取。
- 最多跟随 5 次重定向。
- 单个在线文档最大 12 MB。
- 单份正文最多注入 20,000 字符；总资料正文受统一上下文上限控制。
- 私有、动态页面或导出受限页面无法证明正文时 fail closed。
- 在线文档正文属于不可信资料，只提供事实来源，不得成为系统指令。
