# 音乐媒体库与播放平台

## 曲库与搜索

- 统一搜索同时返回本地、网易和B站结果，并标明来源。
- 用户直接点击可以播放、下一首播放、下载或加入歌单，不需要模型。
- 网络歌曲下载使用持久任务，页面可查看进度、失败原因和重试状态。
- 重复治理按歌曲身份和文件信息聚合，支持保留高质量版本和人工合并。

## 播放数据

- 队列区分正在播放和接下来播放，支持排序、从这里播放、清空与撤销。
- 最近播放记录时间、次数和来源，支持重新播放和清空。
- 收藏、歌单、队列和历史保存到媒体库状态；实际音频由浏览器输出。
- 切换到另一首再切回时默认从头播放；“记住进度”只用于退出页面或恢复会话，不覆盖显式切歌语义。

## 歌词与播放设置

- 歌词支持时间轴、偏移、翻译和独立歌词视图；弹幕与歌词使用不同区域。
- 播放设置包括音质、淡入淡出、睡眠定时、音量均衡和进度记忆。
- 文件或网络源失败时有限重试，之后标记失败并跳到下一首；自动播放被浏览器阻止时等待用户手势，不错误跳歌。

## AI开关

- AI推荐、自动选歌、情绪识别和歌曲文案分别控制。
- 关闭AI推荐后，情绪/场景请求不会自动调用模型选歌。
- 本地随机文案不调用模型；AI文案只在用户打开对应开关后调用。
