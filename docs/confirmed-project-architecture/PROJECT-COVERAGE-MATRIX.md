## 维护门禁

- 新增页面、API前缀、CLI命令、确认文档或专项测试时，必须先更新结构化清单。
- 页面、API、CLI和确认文档必须有唯一主业务域；共享能力通过 `sharedBy` 表达。
- `npm run coverage:check` 校验真实入口、精确路径、测试归属和生成文档一致性。
- `npm run docs:check`、`npm run test:all` 与发布流水线均执行覆盖门禁。
