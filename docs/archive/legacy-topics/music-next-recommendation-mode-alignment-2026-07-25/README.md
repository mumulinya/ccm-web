# 音乐下一首提示与播放模式对齐

## 问题

旧版“下一首推荐”固定展示播放列表中的后一首歌曲。随机播放实际会临时抽取歌曲，单曲循环实际会重播当前歌曲，因此提示内容与真实播放行为不一致。

## 当前行为

- 列表循环：展示队列中的后一首歌曲，末尾回到第一首。
- 随机播放：提前选定一首随机候选，提示区、下一首按钮和自然播放结束共同使用这首候选；切换歌曲后再生成下一次候选。
- 单曲循环：展示当前歌曲，提示文案为“单曲循环”，播放结束后继续播放当前歌曲。
- 只有一首歌曲时，随机模式安全回到当前歌曲。

统一解析函数位于 `frontend/src/utils/musicTrackHelpers.js` 的 `selectNextPlaybackTrack()`。随机候选只在当前歌曲、队列或播放模式变化时更新，避免提示区展示一首、真正播放另一首。

## 验证

- `node scripts/music-next-recommendation-selftest.mjs`
- `npm run build:frontend`
- 浏览器检查列表循环、随机播放和单曲循环三种提示文案及歌曲一致性。
